## 1. クエスト概要

### 短文説明
```
[討伐] 迷宮最深部「深淵」の悪魔王を再封印し、伝説の聖剣を回収せよ。
```

### 長文説明
```
「狭間の迷宮」の最深部、理が崩壊した「次元の深淵」への突入を果たす。
地下11階に足を踏み入れた直後、満身創痍で這いずり戻る他の冒険者パーティと鉢合わせ、深淵の恐怖を警告される。
地下11階は中央ロビーを起点とする4つの玄室（部屋）で構成されており、第一、第二、第三の玄室に潜む魔物を排除してスイッチを起動しなければ、最奥の玄室の扉は開かれない。
最奥の玄室にはテレポートの扉があり、そこを抜けると地下11階最深部のキャンプ地へと到達する。
地下12階の玉座では、かつて討伐したはずの大魔導士ヴァルグナが深淵の再生魔力によって何度でも蘇り、立ちふさがる。
ヴァルグナ（真）を撃破後、プレイヤーが「デーモンスレイヤー」を所持していない場合は、その背後に絶対的な破壊の化身「破壊神 サタン」が顕現し、連戦となる。
サタンを討滅し、伝説の聖剣「デーモンスレイヤー」を勝ち取れ。すでに聖剣を所持している場合は、サタン戦はスキップされクリアとなる。
```

## 4. 主要ノード・ギミック詳細

### Floor 11 (地下11階)
#### 6種のチェストトラップ (玄室1〜4の宝箱で共通適用)
*   宝箱開封時に45%の確率で罠が起動し、以下の比率で多段ネスト抽選されます。
    1.  **毒針 (30%)**: 15%HPダメージ。
    2.  **ガス (25%)**: 25%HPダメージ。
    3.  **魔物の奇襲 (20%)**: `pool_rift_abyss` 通常戦闘。
    4.  **警報 (15%)**: 驚いて軍資金を落とす（ゴールド -1500G）。
    5.  **爆風 (7%)**: 70%HPダメージ。
    6.  **テレポーター (3%)**: 即クエスト失敗帰還。
