## 1. クエスト概要

### 短文説明
```
[報告] 次元の深淵に破壊神を封印したことをギルドへ報告せよ。
```

### 長文説明
```
破壊神サタンの封印に成功した私たちは、その足で冒険者ギルドへと向かう。
ギルド長ガラハドとギルドの人々は、世界の崩壊を免れたことに安堵し、心からの感謝を捧げてくれた。
しかし、ガラハドからは「サタンは封印したが、次元の歪みが生んだ『大穴（裂け目）』自体は未だ完全には塞がっておらず、不安定なまま残されている」ことが告げられる。
ギルド長は、裂け目の監視を続けつつ、内部に眠る貴重な古代のアイテムや秘宝を回収するために、今後も引き続き調査を行う必要があると語る。
静かに危機を脱したものの、未だ見ぬ深淵の脅威に対して引き続き調査を求められる冒険者たちのエピローグ。
```

## 4. ノード詳細

#### `start_prep`（text）
**演出:** bg: bg_office, fg: fg_galahad
```text
大仕事を終え、重い足取りでギルドの扉を開ける。しかし、中に入った瞬間、静かな安堵の混ざった歓声と拍手が私たちを包み込んだ。
```

#### `start`（text）
**演出:** bg: bg_office, fg: fg_galahad
```text
ギルド内の冒険者たちが道を空ける。その先には、いつもの厳格な表情の中に深い安堵を滲ませたギルド長ガラハドが立っていた。
```

#### `text_galahad_01`（text）
**演出:** bg: bg_office, fg: fg_galahad, speaker: ギルド長ガラハド
```text
「おお、無事に戻ったか。次元の底でサタンの気配が封じられたのを魔導観測班が確認した。本当に、あの伝説の破壊神を抑え込んだのだな。」
```

#### `text_galahad_02`（text）
**演出:** bg: bg_office, fg: fg_galahad, speaker: ギルド長ガラハド
```text
「お前たちが成し遂げたのは、単なる悪魔退治ではない。この世界のすべての人々を、破滅の運命から救い出したのだ。ギルドを代表して、心から感謝する。」
```

#### `text_galahad_03`（text）
**演出:** bg: bg_office, fg: fg_galahad
```text
ガラハドは私たちの肩をそっと叩き、大きな勲章と約束された莫大な報酬を手渡した。周囲の冒険者たちも、静かに私たちの健闘を称えてくれた。
```

```text
「だが、これで完全に終わったわけではない。サタンは封印したが、歪みによって生じた『狭間の裂け目』そのものは未だ開いたままであり、不安定な魔力も渦巻いている。」
```

