# 仕様書 v17: 街の噂話 (Gossip) リアルタイムチャットシステム & 自己紹介拡張仕様

## 1. 概要と目的
「街の噂話」は、各拠点画面からアクセス可能なモーダルで動作する、プレイヤー参加型の**リアルタイム双方向チャットシステム**です。
プレイヤーがリアルタイムにメッセージを発信し合えるだけでなく、世界の情勢変化や他のプレイヤーが達成した偉業がシステムアカウント「世界の観測者」によって自動的にチャット上に配信され、常に流動的に変化する世界観を提示することを目的とします。
チャットはグローバルな「ワールドチャット」と、滞在拠点限定の「酒場チャット」に分離して提供されます。

---

## 2. デザイン・UI (チャット形式)
- **チャットタイムラインレイアウト**:
  - DiscordやLINEのような、縦スクロール型のチャットタイムライン画面。
- **バルーン（吹き出し）表示**:
  - **自分の発言**: 画面右側に整列。アバターと名前を表示し、吹き出しはダークゴールド調（または青・金グラデーション）の背景。
  - **他プレイヤーの発言**: 画面左側に整列。アバターと名前を表示し、吹き出しはチャコールグレー等のダークトーン背景。
  - **システムメッセージ**: 画面中央に配置。アバターは「世界の観測者」、名前は「世界の観測者（システム）」とし、神秘的なダークパープル調のフラットな通知カード形式で表示します。
- **メッセージ入力エリアの常時表示**:
  - モーダル画面の最下部にテキスト入力欄（140文字上限、残文字カウント表示）および「送信」ボタンを常時固定配置します（従来の「＋」ボタンによる別窓ポップアップ形式は廃止）。
- **最上段固定（ピン留め）エリア**:
  - チャンネルに関わらず、最新の重要システムアナウンス1件をチャットエリアの最上部に固定表示（ピン留め）します。
  - 背景はダークパープルのグラデーションとし、アバターには宝石をモチーフにしたグラフィック（`/images/icons/observer_gem.png`）を使用します。
- **リアルタイム同期とスクロール制御**:
  - Supabase Realtime（`supabase.channel`）を使用したリスナーを常時接続します。チャット画面を開いている間、他のプレイヤーの発言やシステムメッセージがリアルタイムで「シュッ」と下部に滑り込むようにアニメーション挿入されます。
  - メッセージ送信時、または自分がスクロールの最下部付近にいる状態で新規メッセージを受信した場合は、自動で最下部までスムーズスクロール（`scrollIntoView`）します。
- **履歴の永続化と初期ロード**:
  - チャットを開いた際に、過去ログとして最新の30件を自動ロードします。スクロールを上部に引っ張ることで、さらに過去のログを30件ずつ非同期で追加ロード（無限スクロール）します。
- **システム表示トグルの永続化**:
  - ヘッダー右側に「システム表示 ON/OFF」の切り替えトグルを配置。トグルの選択状態は `localStorage`（`wirth_dawn_gossip_hide_system`）に保存され、起動時に引き継がれます。

## 3. データベース & API設計

### 3.1 `gossip_posts` テーブル
- `id` (bigint, PK, identity): 投稿の一意なID。
- `user_id` (uuid, FK user_profiles.id, nullable): 投稿ユーザーID。システムメッセージの場合は NULL。
- `name` (text, not null): 投稿者の名前（投稿時のスナップショット）。
- `epithet` (text, nullable): 投稿者の称号（投稿時のスナップショット）。
- `avatar_url` (text, nullable): 投稿者のアバターアイコンURL。
- `content` (varchar(140), not null): 噂本文（最大140文字）。
- `location_id` (uuid, FK locations.id, nullable): 投稿時の滞在拠点ID。ワールドチャットの場合は NULL。
- `location_name` (text, nullable): 投稿時の滞在拠点名（ワールドチャットの場合は NULL）。
- `is_system` (boolean, default false): システムによる自動投稿フラグ。
- `created_at` (timestamptz, default now()): 投稿されたリアル日時。

#### インデックス
- `gossip_posts_created_at_idx` ON `gossip_posts(created_at DESC)` (追加読み込み・ソート高速化用)

#### RLSポリシー (Row Level Security)
- `SELECT`: 認証済みユーザーであれば全件閲覧可能。
- `INSERT`: 認証済みユーザーは `user_id = auth.uid()` かつ `is_system = false` の条件で挿入可能。`content` が140文字以下であることを検証。

### 3.2 API エンドポイント
- **`GET /api/gossip`**
  - パラメータ:
    - `limit` (デフォルト30): 取得件数。
    - `offset` (デフォルト0): 追加読込オフセット。
    - `channel` (`global` / `local`): チャンネル指定。
    - `locationId` (UUID, オプション): `channel=local` の場合に必須。
  - レスポンス:
    - `pinned_system_post`: 最新の重要システムメッセージ1件。
    - `posts`: 該当チャンネルのメッセージリスト（`created_at DESC`）。
      - `channel=global` の場合: `location_id IS NULL` の発言、および `is_system = true` の発言を取得。
      - `channel=local` の場合: `location_id = locationId` かつ `is_system = false` の発言のみを取得。
- **`POST /api/gossip`**
  - 送信データ: `{ content: string, isGlobal?: boolean }`
  - バリデーション:
    - 140文字以下であること。
    - 直前投稿から**「10秒」**経過していること（10秒以内の連続投稿は `429 Too Many Requests` エラー）。
    - 禁止ワードフィルタ（誹謗中傷、ハラスメントワード等）に抵触していないこと（抵触時は `400 Bad Request` エラー）。
  - 送信処理:
    - `isGlobal` が true（ワールドチャット宛）の場合、`location_id` と `location_name` を `null` に設定して `gossip_posts` に挿入します。
    - `isGlobal` が false または省略（酒場チャット宛）の場合、送信者の現在地 `current_location_id` およびその拠点名を取得して挿入します。

## 4. システムメッセージ（自動投稿）仕様とノイズケア

「世界の観測者」が自動で書き込みを行うトリガー条件およびメッセージテンプレートは以下の通りです。
**※注意（管理者除外仕様）: 本番環境の管理者およびテストユーザーによる各イベントは、システム自動投稿のトリガー対象から除外されます。**

### 4.1 システムメッセージのノイズ間引きケア (v17.6アップデート)
チャットのリアルタイム化に伴い、NPCの移動ログなどの頻度の高いシステムメッセージがチャットに流れると会話を妨げるため、チャットへ配信するメッセージを**「プレイヤーによる重大な実績」**に厳選します。
- **チャット配信対象**:
  - メインクエストの節目・最終話クリア
  - 高難度スポット・伝説級ボス・狭間の迷宮の討伐
  - プレイヤーの特定の高レベル到達、アライメント称号獲得、図鑑完成
  - 新たな英霊（`shadow_heroic`）の登録、およびプレイヤーキャラクターの転生
- **チャット配信対象外（世界履歴にのみ記録）**:
  - NPCの移動シミュレーションログ（「〇〇がAからBへ移動した」）
  - 日常的な環境・情勢ログ

## 5. 自己紹介ポップアップ (`SimpleUserProfilePopup`) の要素拡張 & 購読プラン（フレーム）表示
- タイムライン取得（`/api/gossip`）にて、投稿ユーザーの `subscription_tier` を結合取得し、アバターアイコンに専用のフレームを適用します。
  - **Premium**: ゴールドグラデーション枠
  - **Basic**: ブルースチールグラデーション枠
  - **Free / システム**: 従来のブロンズ/グレー枠（システムはパープル枠）
- 詳細プロフィール画面（`/api/profile`）でも `subscription_tier` を含めて返却し、アバターと連動させます。

---

## 6. 未閲覧ユーザー向けの最新投稿バルーン表示
- `localStorage.last_viewed_gossip_time` と最新のチャット投稿時間を比較し、未読がある場合は拠点画面の「街の噂話」アイコン下部に吹き出しを表示して、最新メッセージの冒頭をアピールします。モーダルを開いた時点で既読となり吹き出しは非表示になります。

## 7. 旧仕様のクリーンアップ
リアルタイムチャット移行に伴い、不要となる旧BBSのコード（旧4タブ用クエリ、フォーマットヘルパー、タイプライター演出用コンポーネントなど）は全面的にクリーンアップされます。
